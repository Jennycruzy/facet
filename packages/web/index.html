Amounts and timing stay public

Two identities funded with the same amount, seconds apart, are correlated in practice whatever the cryptography says.

The identity is visible, its owner is not

Anyone can see the account exists and what it did. Only the link back to you is hidden.

A careless action undoes it

If the action names you, the receipt links it back. Our first test run did exactly that, and we wrote it up rather than quietly fixing it.

Six minutes, every time

Every action is proved before it lands, deposits and swaps alike. That is the real cost of the privacy, and the interface shows the stages rather than a spinner.
