Honest boundary

No silent signing

Wallet binding and viewing-key derivation are implemented as an in-memory browser flow. The three links above are the separate reviewed Wallet API execution paths; the generic EOA queue shown here does not submit arbitrary calls. The current development prover takes several minutes; signing the message above does not move funds or authorize a transaction. The evidence page remains the place to verify completed receipts.
