How it works

Three actions,
one transaction.

A shielded note pays for an identity that does not exist yet, that identity acts, and the change returns to the shield. Facet first executed this sequence on Sepolia on 25 August 2026; the current Mainnet integration evidence is listed below.

What we cannot claim
Stated before anyone asks

    

      
Not a new privacy protocol

      
It uses StarkWare's anonymizer unmodified. What is new is the funding pattern, the
      SDK path, and the first execution of it.

      
Not the only users

      
Most compute path calls on mainnet belong to other teams' anonymizers.

      
Not the first to fund one

      
Seven mainnet transactions did it first, the public way. That is the comparison
      above, not a strawman.

      
Our own test linked an identity

      
The first run sent one wei to the owner's address because it was a smoke test, so
      that receipt does connect them. The argument rests on the funding leg, which is
      shielded.

      
Two routes, one boundary

      
Ekubo and Endur have successful wallet-mediated Mainnet receipts. The launcher exposes
      only these receipt-backed routes; unsupported protocols are outside the current product.
